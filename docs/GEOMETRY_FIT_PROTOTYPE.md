# Multi-view geometry-fit prototype

Branch: `experiment/geometry-fit-prototype`

## Goal

Test a third direction without replacing either existing 3D export path. The prototype keeps the source anatomy primitives and fits a small number of bounded semantic-group transforms against silhouettes rendered by the original 2D renderer.

It does **not** reconstruct a volume from captured depth. It also does not change the original 2D renderer, genetics, or seed generation.

## How it works

1. Capture the original 2D silhouette at eight evenly spaced yaw angles.
2. Build a lightweight triangle projection from the existing ellipsoids, round cones, and triangle primitives.
3. Measure silhouette IoU for every reference view.
4. Run deterministic coordinate descent over a small set of semantic groups (`body`, `head`, `neck`, `arms`, `legs`, `tail`, `torso`, `pelvis`, `thorax`, `abdomen`, `wing(s)`, `fin(s)`).
5. Each group can receive only a small uniform scale adjustment (at most 8%) and a small world-space offset (at most 0.5 source pixels). A candidate is accepted only when the combined mean/worst-view score improves.
6. Export the fitted anatomy through the existing OBJ exporter so the preview shows the actual current export pipeline, not the proxy triangles used by the objective.

The fitted anatomy is a clone. The source anatomy object is not mutated.

## Preview

Open `examples/preview_3d/CreaturePreview3D.tscn` in Godot 4.7.1 .NET and run it with F6.

Enable **几何拟合原型（实验 / 不含装备）**. The reference thumbnail shows the original 2D render. The status text reports initial/fitted proxy IoU, worst-view IoU, the number of adjusted regions, objective evaluations, and the chosen parameters.

The geometry-fit toggle and the multi-view depth-reconstruction toggle are mutually exclusive. The original OBJ mode remains the default.

## Important limitations

- The IoU objective uses a lightweight triangulated projection of source primitives, **not** the final SDF-unified OBJ. It is a fast proxy for testing whether small geometry adjustments can align silhouettes.
- The final exported model is still generated by the existing SDF/body and attachment pipeline. A better proxy IoU does not guarantee a better final mesh.
- This first pass adjusts only semantic-group scale and translation. It does not optimize per-primitive shape, bone locations, local rotations, topology, or materials.
- The optimizer may trade a small improvement in one view for a larger improvement in the weighted multi-view score. Inspect front, side, rear, and intermediate angles.
- Equipment is disabled in this mode. Animation, skinning, and UVs are not included.
- The fit runs synchronously from the preview UI and may briefly block the main thread.
- The result must not be treated as validated until the .NET tests pass and the fixed-seed model has been inspected in Godot.

## Acceptance criteria

For a fixed seed, compare the original OBJ mode and geometry-fit mode:

1. The mean and worst-view proxy IoU should be reported accurately and be deterministic.
2. The final OBJ should have no newly detached limbs, floating facial details, or obvious gaps introduced by fitting.
3. Front, side, rear, and 45-degree silhouettes should improve or remain visually stable.
4. If proxy IoU improves but the final OBJ looks worse, do not widen the parameter bounds. Replace the proxy objective with one based on the actual exported mesh silhouette before continuing.
